# Shelly — умная розетка в телефоне

Android 12+ (minSdk 31). Управление розеткой Shelly и её метрики — напрямую по локальной сети (HTTP), без облака. Material 3 / Material You.

- **Вход** — IP + пароль; «Запомнить пароль» шифрует его AES-GCM ключом из Android Keystore (`data/Prefs.kt`, `SecretBox`). Список сохранённых розеток, автовход в последнюю. Для Gen1 можно сменить логин (по умолчанию `admin`). Демо-режим — без устройства.
- **Главный экран** — большая кнопка вкл/выкл, текущая мощность; напряжение, ток, частота, cos φ, температура, Wi‑Fi (показывается то, что измеряет модель); график мощности 5/15/60 мин с мин/средн/макс; энергия за сегодня / сеанс / всего и стоимость по тарифу; таймер «выключить/включить через»; сведения об устройстве.
- **Настройки розетки** — имя, состояние после подачи питания, лимит мощности, автовыключение, сброс счётчика (Gen2+), перезагрузка.
- **Уведомления** (каждое: выкл / уведомление / будильник): высокая мощность (порог), нагрузка завершила работу (стиралка/зарядка), авария розетки, переключение не из приложения, потеря связи. «Фоновый мониторинг» — служба переднего плана, опрос раз в 10–60 с, переживает перезагрузку (нужен сохранённый пароль).
- **Тема**: системная / светлая / тёмная / AMOLED, цвета из обоев.

## Протокол

- Gen2/3/4 (Plus Plug S, Plug S Gen3, Outdoor Plug…): `GET /rpc/<Method>?…`, Digest SHA-256 (пользователь `admin`). `Shelly.GetStatus`, `Switch.Set` (`toggle_after` — таймер), `Switch.GetConfig/SetConfig`, `Switch.ResetCounters`, `Sys.SetConfig`, `Shelly.Reboot`.
- Gen1 (Plug, Plug S): `/status`, `/relay/0?turn=…&timer=…`, `/settings`, Basic-авторизация. Счётчик в Вт·мин.
- Поколение и необходимость пароля определяются по `GET /shelly` (без авторизации).

## Сборка

```
ci/remote_build.sh   # сборка на ноде, APK → dist/ и ~/Downloads (с проверкой SHA-256)
ci/release.sh ["что нового"]   # сборка + MEGA (2 версии) + site/release.json + push + Discord
```
Сайт — `site/` (GitHub Pages). Версия — `appVersion` в `app/build.gradle.kts`. Ключ подписи — `keystore/` (вне git).
